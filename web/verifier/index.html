Is this record genuine, and is this the file it describes?

Drop a FaceProof record (.json) and, optionally, the image. This page recomputes the hash, checks the signature and the Bitcoin timestamp, and tells you what that does and does not prove. It never detects or compares a face.

Require a specific signer

A valid signature alone proves a key signed the record, not whose key it is. Pinning checks it is the key you expect.

What this page sent over the network

Only GET requests for public Bitcoin block headers, and only when a record carries a Bitcoin timestamp. Nothing here contains your files.

  • No requests yet.

What a pass does not mean

  • It does not prove the image is real, unedited before it was recorded, or who made it.
  • A signature proves a key signed the record; it says nothing about who holds the key unless you pinned it.
  • A Bitcoin timestamp proves the record hash existed by that block, not when the picture was taken.
  • It checks the exact file bytes. A resized, re-encoded or screenshotted copy will not match, by design.
  • Records anchored on an EVM registry can only be checked with the command-line tool.
